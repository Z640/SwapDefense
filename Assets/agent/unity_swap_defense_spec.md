# Unity 게임 개발 명세서: 체력 교환 디펜스 (Swap Defense)

본 문서는 '3D게임 제작 실습 기획서'를 바탕으로 Unity 엔진에서 메인 로직과 프로토타입을 즉각 구축할 수 있도록 작성된 기술 명세서입니다. AI 코딩 에이전트(agy)는 아래의 모든 수치, 규칙, 판정 공식을 엄격히 준수하여 스크립트와 씬 구조를 설계해야 합니다.

---

## 1. 프로젝트 개요 및 환경 설정
* **장르:** 탑다운 고정 위치 디펜스 / 무한 생존
* **플랫폼:** PC 웹 (Unity WebGL 또는 PC Standalone)
* **핵심 주제:** 교환 (Swap) - 지속적으로 감소하는 플레이어의 체력을 몬스터와 맞바꾸며 생존
* **종료 조건:** 플레이어 현재 체력이 $0$ 이하가 되면 게임 오버 (승리 화면 없음, 무한 생존)
* **시점 및 좌표계 권장사항 (중요):**
  * 기획서의 모든 거리/속도 단위가 픽셀(`px`)로 정의되어 있습니다.
  * **방안 A (권장):** Camera의 Projection을 `Orthographic`으로 설정하고, 화면 해상도 기준 $1\text{ unit} = 1\text{ px}$ 또는 $1\text{ unit} = 100\text{ px}$ 비율로 통일하여 계산합니다. (예: `Orthographic Size = 540`일 때 세로 $1080\text{px}$이 $1:1$ 매칭됨)
  * **방안 B:** 3D 월드 좌표를 사용할 경우, `PixToUnit = 0.01f` 상수를 두어 기획서의 모든 `px` 수치를 변환하여 적용합니다.
  * **판정 방식:** 유니티 기본 물리 컴포넌트(`Collider`)의 도형 형태에 의존하지 않고, **중심점 기준 원형 거리(거리 제곱 비교 또는 `Vector2.Distance` / `Vector3.Distance`)로 직접 수학적 판정**을 수행하는 것을 권장합니다.

## 2. 전장 구성 및 조작 체계

### 2.1 전장 레이아웃 (예시 이미지 기준)
* **몬스터 스폰 구역:** 화면 상단 외곽 또는 상단 지정 라인.
* **이동 경로:** 몬스터는 상단에서 등장하여 화면 하단의 **방어선 (`DEFENSE LINE`, 담)**을 향해 직선(아래쪽 방향)으로 이동합니다.
* **방어선 (담):** 화면 하단부에 가로로 배치된 경계선입니다. 담 자체에는 별도의 체력이 없으며, 몬스터가 이 선의 $Y$좌표(또는 $Z$좌표)에 도달하면 즉시 플레이어에게 도착 피해를 입히고 소멸합니다.
* **플레이어 (`YOU`):** 화면 하단 중앙, 방어선(담) 바로 뒤에 위치가 고정되어 있으며 **이동할 수 없습니다.**

### 2.2 조작 매핑 (Input)
| 입력 | 동작 | 세부 규칙 |
| :--- | :--- | :--- |
| **마우스 이동** | 조준 (Aim) | 마우스 커서의 월드 좌표를 실시간으로 추적하여 조준점 표시 및 타겟 판별 |
| **F 키** | 사격 (Fire) | 단발 사격 및 **길게 누르고 있으면(Hold) $0.25$초 간격으로 연속 발사** |
| **Q 키** | 체력 교환 (Swap) | 현재 마우스 조준점에 선택된 몬스터와 플레이어의 현재 체력을 즉시 맞바꿈 |
| **Esc 키** | 일시정지 / 재개 | 인게임 진행 중 `Time.timeScale` 제어 및 일시정지 팝업 토글 |

## 3. 핵심 오브젝트 수치 및 판정 데이터

### 3.1 플레이어 (Player)
| 항목 | 수치 | 비고 |
| :--- | :--- | :--- |
| **최대 / 시작 체력** | $100.0$ / $100.0$ | 소수점 연산 지원 (`float`), 최대 체력 $100$을 초과할 수 없음 |
| **지속 체력 감소** | 초당 $3.0$ 감소 | 매 프레임 `3.0f * Time.deltaTime`만큼 체력 차감 |
| **공격 피해량** | $12.0$ | 탄환 1발당 데미지 |
| **공격 간격 (연사 쿨타임)** | $0.25$초 | 초당 최대 4발 발사 가능 |
| **체력 교환(Q) 쿨타임** | $6.0$초 | 교환 성공 시에만 쿨타임 적용 |

### 3.2 탄환 (Bullet) 및 사격 판정
* **탄환 이동 속도:** $840\text{ px/초}$
* **탄환 시각 반경:** $3\text{ px}$
* **이동 궤적:** 발사 당시 플레이어 위치에서 마우스 조준 방향(`Normalized Direction`)으로 직선 이동합니다.
* **충돌 및 관통 규칙:**
  * 탄환 한 발은 적 한 마리에게만 1회 피해를 주고 즉시 제거됩니다(관통 불가).
  * 판정은 도형 모양이 아닌 **중심 기준 원형 거리**로 계산합니다.
  * 한 프레임의 이동 구간(이전 프레임 위치 $P_{\text{prev}}$ ~ 현재 프레임 위치 $P_{\text{curr}}$ 선분) 내에 여러 적과 동시에 충돌 조건을 만족할 경우, **발사 원점(또는 $P_{\text{prev}}$)에서 가장 먼저 만나는 적 한 마리**만 맞힙니다.

### 3.3 몬스터 (Monster) 데이터 테이블
몬스터는 이동 중 공격하지 않으며, 방어선(담)에 도착하면 플레이어에게 피해를 1회 주고 즉시 소멸합니다.

| 항목 | 빠른 적 (Fast Enemy) | 느린 적 (Slow Enemy) | 비고 |
| :--- | :--- | :--- | :--- |
| **최대 / 시작 체력** | $100.0$ / $30.0$ | $100.0$ / $90.0$ | 스폰 시 시작 체력으로 생성 (최대 체력은 $100$) |
| **일반 이동 속도** | $84\text{ px/초}$ | $42\text{ px/초}$ | 체력 교환 전 기본 이동 속도 |
| **돌진 이동 속도** | $252\text{ px/초}$ | $252\text{ px/초}$ | **체력 교환 직후 종류에 관계없이 동일하게 적용** |
| **일반 도착 피해** | $10.0$ | $20.0$ | 교환하지 않은 일반 상태로 담에 도착 시 피해량 |
| **돌진 도착 피해** | 도착 당시 **남은 현재 체력** | 도착 당시 **남은 현재 체력** | 교환된 적이 담에 도착할 때 입히는 피해량 |
| **외형 (Visual)** | 작은 주황색 마름모 | 큰 보라색 육각형 | 3D/2D 메쉬 또는 스프라이트로 구현 |
| **몸체 반경** | $15\text{ px}$ | $24\text{ px}$ | 기본 크기 기준 |
| **사격 피격 여유** | $+10\text{ px}$ | $+3\text{ px}$ | 탄환 판정 보정치 |
| **최종 사격 피격 반경** | **$25\text{ px}$** | **$27\text{ px}$** | 탄환 중심과 적 중심 거리가 이 값 이하일 때 명중 |
| **Q 선택 반경** | **$15\text{ px}$** | **$24\text{ px}$** | 마우스 조준점과 적 중심 거리가 이 값 이하일 때 선택 |

## 4. 핵심 메커니즘 상세 규칙

### 4.1 조준점 타겟팅 (Q 선택 우선순위)
매 프레임 마우스 조준점 위치($M$)와 살아있는 모든 몬스터의 중심 위치($E_i$) 사이의 거리를 계산합니다.
1. 거리 $d = \|M - E_i\| \le \text{Q 선택 반경}$ ($15\text{ px}$ 또는 $24\text{ px}$) 조건을 만족하는 몬스터들을 후보군으로 추립니다.
2. 후보군에 여러 적이 겹쳐 있을 경우, **조준점($M$)에서 적 중심($E_i$)까지의 거리가 가장 가까운 적** 1마리를 최종 선택(`Selected Target`)합니다.
3. 만약 거리가 완전히 같다면, **먼저 생성된(스폰 ID가 빠른) 적**을 우선 선택합니다.
4. **이미 돌진 중인 적도 선택(재교환)할 수 있습니다.**
5. 선택된 적은 **민트색 테두리**로 강조 표시합니다. (돌진 중인 적이 선택된 경우, **민트색 선택 테두리가 붉은색 돌진 테두리보다 우선**하여 표시됩니다.)

### 4.2 체력 교환 (Swap) 및 돌진 (Dash) 로직
플레이어가 `Q` 키를 눌렀을 때 다음 순서로 판정합니다.
1. **발동 조건 확인:**
   * 현재 Q 스킬이 쿨타임 중이거나, 조준점에 선택된 대상(`Selected Target`)이 없다면 **발동하지 않으며 쿨타임도 소모하지 않습니다.** (이때 화면에 "대상 없음" 또는 "쿨타임" 안내 UI를 약 $1.8$초간 표시)
2. **체력 맞교환:**
   * 플레이어의 현재 체력($HP_P$)과 대상 몬스터의 현재 체력($HP_M$)을 즉시 맞바꿉니다.
   * 교환 순간 두 객체의 체력 총합은 그대로 유지됩니다.
   * 예시: 플레이어 체력 $40$, 적 체력 $90$에서 교환 $\rightarrow$ 플레이어 체력 $90$, 적 체력 $40$이 됨.
3. **돌진 상태 전환:**
   * 체력을 교환한 몬스터는 즉시 **'돌진(Dash) 상태'**가 됩니다.
   * 이동 속도가 종류에 상관없이 즉시 **$252\text{ px/초}$**로 변경됩니다.
   * 돌진 몬스터가 방어선(담)에 도착하면, 고정 피해가 아니라 **도착 당시 몬스터에게 남은 현재 체력만큼** 플레이어에게 피해를 줍니다.
   * 돌진 중인 몬스터를 사격(`F`)하여 체력을 깎으면 도착 피해량도 그만큼 줄어들며, 도착 전에 처치(체력 $0$ 이하)하면 아무런 피해를 받지 않고 처치 수(`Kill Count`)가 $1$ 증가합니다.
   * 예시: 교환 후 체력이 $40$이 된 돌진 적을 플레이어가 2발($12 \times 2 = 24$) 맞히면 적 체력이 $16$이 되어, 담에 도착 시 피해량도 $16$으로 감소합니다.

## 5. 웨이브 스폰 및 난이도 디자인

* **초기 딜레이:** 게임 시작 후 **첫 몬스터는 $1.0$초 후**에 등장합니다.
* **시간대별 스폰 테이블:** 생존 시간(`Survival Time`)에 따라 등장 간격과 생성 패턴(반복 순서)이 변화합니다.

| 생존 시간 구간 | 등장 간격 (Spawn Interval) | 생성 반복 순서 (Pattern Loop) |
| :--- | :--- | :--- |
| **$0.0\text{초} \sim 20.0\text{초}$** | $2.4\text{초}$ | `빠른 적` $\rightarrow$ `빠른 적` $\rightarrow$ `느린 적` (3마리 주기 반복) |
| **$20.0\text{초} \sim 40.0\text{초}$** | $1.8\text{초}$ | `빠른 적` $\rightarrow$ `느린 적` (2마리 주기 반복) |
| **$40.0\text{초}$ 이후 (무한)** | $1.3\text{초}$ | `빠른 적` $\rightarrow$ `빠른 적` $\rightarrow$ `느린 적` (3마리 주기 반복) |

* $40$초 이후에는 동일한 난이도($1.3$초 간격, 빠름-빠름-느림)를 계속 유지하며 제한 시간 없이 플레이어가 사망할 때까지 진행합니다.
* 몬스터의 스폰 $X$좌표는 전장 상단 범위 내에서 랜덤하게(단, 화면 밖으로 잘리지 않게 몸체 반경만큼 여백을 두고) 생성되도록 구성합니다.

## 6. UI 및 시각 피드백 (VFX) 명세

기획서 3페이지의 표와 4페이지의 레이아웃 이미지를 기준으로 UI와 이펙트를 구현합니다.

### 6.1 상단 HUD 및 인게임 정보 UI
| UI 요소 | 표시 형식 및 규칙 |
| :--- | :--- |
| **플레이어 체력** | `PLAYER / 체력` 라벨, **소수 첫째 자리 / 100** 텍스트 (예: `64.6 / 100`) 및 가로 체력 막대(Bar) |
| **체력 경고 상태** | 플레이어 체력이 **$25.0$ 이하**일 때 체력 숫자와 가로 막대를 **붉은색**으로 변경하여 강조 |
| **생존 시간** | `생존 시간` 라벨, **소수 첫째 자리까지 초 단위** 표시 (예: `11.8 s`) |
| **처치 수** | `처치` 라벨, 해당 판에서 사격으로 처치한 적의 수 (예: `02` 또는 정수 표기, 담에 부딪혀 자폭한 적은 제외) |
| **Q 쿨타임** | `Q / 현재 체력 교환` 라벨, 준비 완료 시 **`사용 가능 ↔`**, 쿨타임 중일 때는 **남은 초(소수 첫째 자리 권장)** 및 게이지 표시 |
| **하단 타겟 정보창** | 화면 하단에 `TARGET /` 영역 배치. 현재 마우스로 선택한 적의 **종류와 소수 첫째 자리 체력**을 표시 (미선택 시 기본 안내 문구: `"빠른 적 30 HP · 느린 적 90 HP · 교환한 적은 남은 체력만큼 도착 피해를 줍니다. F로 맞히면 피해도 줄어듭니다."`) |
| **조작 가이드** | 플레이어(`YOU`) 하단 또는 화면 한쪽에 `마우스 조준 · F 공격 · Q 체력 교환 · Esc 일시정지` 상시 표시 |

### 6.2 월드 스페이스(몬스터) UI 및 시각 효과
| 요소 | 표시 방식 및 지속 시간 |
| :--- | :--- |
| **적 기본 체력 표시** | 몬스터 몸체 바로 위에 **올림 정수(`Mathf.CeilToInt(hp)`)**로 숫자 표시, 체력 막대(Bar)는 **실제 비율(`currentHp / 100f`)**로 렌더링 |
| **선택한 적 강조** | 조준점 내에 들어와 선택된 적 외곽에 **민트색 테두리** 표시 (돌진 테두리보다 우선순위 높음) |
| **돌진 적 시각 표시** | **붉은 테두리**, 이동 시 **잔상선(Trail)**, 담을 향한 **방향선(Line)**, 그리고 몸체 근처에 **예상 도착 피해량(현재 체력 수치)** 강조 표시 |
| **사격 명중 효과** | 탄환이 적에게 명중했을 때 피격 반짝임/이펙트 (**약 $0.18$초** 지속) |
| **플레이어 피격 효과** | 적이 담에 도달해 플레이어가 피해를 입었을 때 화면 흔들림 또는 붉은 점멸 효과 (**약 $0.35$초** 지속) |
| **체력 교환(Q) 연출** | 교환 성공 시 플레이어와 대상 적을 잇는 **교환 연결선** 및 **교환 전후 체력 변화 수치($\text{이전 체력} \rightarrow \text{이후 체력}$)** 플로팅 표시 (**약 $0.8$초** 지속) |
| **시스템 알림 텍스트** | 대상 없이 Q 입력, 쿨타임 중 Q 입력, 또는 교환 직후 돌진 경고 안내 텍스트 표시 (**약 $1.8$초** 지속) |

### 6.3 게임 상태별 화면 (Scene / Panel Flow)
단일 씬(Single Scene) 내에서 UI 패널을 전환하는 방식으로 구현합니다.
1. **시작 화면 (Title Panel):** 게임 핵심 규칙 요약 텍스트와 `[시작]` 버튼 표시.
2. **일시정지 화면 (Pause Panel):** 인게임 중 `Esc` 입력 시 활성화. `[계속하기]` 버튼 표시 (`Esc` 재입력으로도 해제 가능).
3. **결과 화면 (Game Over Panel):** 플레이어 체력이 $0$이 되면 활성화. 해당 판의 최종 **생존 시간**, **처치 수**, 그리고 `[다시 시작]` 버튼 표시. (승리 화면은 없음)

### 7.2 AI 에이전트(agy)를 위한 권장 스크립트 구조
유니티에서 빠르고 버그 없이 구현하기 위해 아래의 모듈 구조로 C# 스크립트를 작성해 주세요.

1. `GameConstants.cs`
   * 기획서의 모든 수치(체력 $100$, 초당 감소 $3$, 공격력 $12$, 연사 $0.25$초, Q 쿨타임 $6$초, 탄속 $840$, 적 스탯 등)를 `const float`로 한곳에 모아 관리합니다.
2. `GameManager.cs`
   * 게임 상태(`Title`, `Playing`, `Paused`, `GameOver`) 관리, 생존 시간 타이머, 처치 수 집계, `Esc` 일시정지 토글, 게임 재시작 로직을 담당합니다.
3. `PlayerController.cs`
   * 플레이어 현재 체력 관리(초당 $3$ 감소 및 $0$ 이하 시 게임오버 호출), 마우스 월드 좌표 추적, `F` 키 연속 사격 쿨타임 처리, `Q` 키 체력 교환 및 $6$초 쿨타임 처리를 담당합니다.
4. `Monster.cs`
   * 적 종류(`Fast`, `Slow`), 생성 순서 ID, 현재 체력, 돌진 여부(`isDashing`), 이동 로직, 방어선 도달 시 데미지 전달 및 소멸, 월드 UI(올림 정수 체력 텍스트, 체력바, 민트/붉은 테두리, 방향선) 갱신을 담당합니다.
5. `WaveSpawner.cs`
   * 첫 $1$초 대기 후, 생존 시간 구간($0\sim 20$초, $20\sim 40$초, $40$초~)에 맞춘 스폰 쿨타임 및 패턴 큐(`Fast-Fast-Slow` 또는 `Fast-Slow`)에 따라 몬스터를 생성하고 활성 몬스터 리스트(`List<Monster>`)를 관리합니다.
6. `CombatSystem.cs` (또는 `Bullet.cs` 내장)
   * 탄환의 직선 이동($840\text{ px/s}$) 및 매 프레임 선분-원 거리 판정(가장 먼저 만나는 적 1마리 피격 처리).
   * 마우스 조준점과 활성 몬스터들 간의 거리 판정($15\text{ px}$ / $24\text{ px}$) 및 최단 거리(동률 시 스폰 ID 순) 타겟 선정을 수행합니다.
7. `UIManager.cs` 및 `VFXManager.cs`
   * 상/하단 HUD 갱신(소수점 첫째 자리 포맷팅 `F1`, 체력 $25$ 이하 붉은색 경고), 명중($0.18$초)/피격($0.35$초)/교환선($0.8$초)/안내문구($1.8$초) 타이머 이펙트를 제어합니다.
